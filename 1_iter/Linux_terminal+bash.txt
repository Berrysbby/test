1)Используя документацию или вывод только man/--help, найдите и выпишите в отдельный файл grep_keys.txt через пробел:
какой ключ включает поиск без учёта регистра;
какой ключ выводит номер строки;
какой ключ позволяет искать целое слово, а не часть слова.
Ответ: echo "-i -n -w" > grep_keys.txt

2) Выяснить в каком каталоге расположен файл my_file.c.
Ответ: which my_file.c

3)Необходимо переместить файл src/data.txt в директорию backup/ ( полное имя - backup/data.txt), но только если:
backup/data.txt не существует, или src/data.txt новее, чем backup/data.txt.
Ответ: mv -u src/data.txt backup/data.txt

4)Есть файл /home/vero/task_1/report.txt. Нужно скопировать его так, чтобы получился не дубль, а жёсткая ссылка с именем report.link.txt в новой папке /home/vero/task_1_link/report.txt.
Ответ: mkdir -p /home/vero/task_1_link && cp --link /home/vero/task_1/report.txt /home/vero/task_1_link/report.link.txt 

5)Дан файл notes.txt. Нужно вывести его в обратном порядке с выполнением следующих требований:
Вывести строки файла в обратном порядке (последняя строка выводится первой).
Пустые строки не выводить;
Вывести только первые N строк результата (N задаётся переменной окружения N, если N не задана — вывести 10).
В конце допечатать строку:
PRINTED=<число> — сколько строк реально было выведено.
Вся обработка должна быть сделана командами терминала с использованием операторов | &.
Ответ: N="${N:-10}"; tac notes.txt | grep -vE '^[[:space:]]*$' | head -n "$N" | awk '{print; c++} END{print "PRINTED=" (c+0)}'

6)Сформируйте команду, которая покажет список уникальных имён пользователей, которые сейчас залогинены, в алфавитном порядке.
Для каждого пользователя выведет количество его сессий (сколько строк в who относится к этому пользователю) в виде:
<username> <count>
Отдельно в конце выведет строку вида: TOTAL_SESSIONS=<N> — общее число активных сессий.
Можно только команду who с соответствующими ключами.
Итоговая команда должна быть получена через несколько команд, соединённых оператором |.
Ответ: who | awk '{u[$1]++; total++} END{for (name in u) printf "%s %d\n", name, u[name]; printf "TOTAL_SESSIONS=%d\n", total}' | sort -k1,1



Скрипты:
1) Напишите скрипт init_lab.sh, который:
создаёт директорию workdir (если уже есть — аккуратно обрабатывает это),
создаёт внутри workdir файлы app.log, app.tmp, readme.txt,
записывает в user_data.txt одну строку с текущим логином пользователя из переменной окружения ($USER) и текущей датой (через переменную окружения).
Требование: использовать && так, чтобы при ошибке создания директории дальнейшие действия не выполнялись.

2) Напишите скрипт find_lines.sh, который:
принимает 2 аргумента: путь_к_файлу и шаблон_поиска,
проверяет, что файл существует (если нет — выводит понятное сообщение и завершает работу с ненулевым кодом),
выводит все совпадения grep так, чтобы:
был показан номер строки,
поиск был без учёта регистра,
и дополнительно в конце скрипт выводил строку: EXIT_CODE=<код> (код возврата последней команды grep).
Требование: корректно обработать ситуацию “совпадений нет” (это не ошибка выполнения скрипта как программы, но код grep будет особым — нужно правильно это показать).

3)Напишите скрипт cleanup.sh, который:
принимает 1 аргумент: путь к директории,
внутри неё ищет файлы с расширением .tmp (можно считать, что такие имена встречаются в выводе какого-то списка),
печатает список найденных .tmp файлов,
затем удаляет их, но:
ошибки удаления складывает в cleanup_errors.log,
в терминал выводит только успешные действия (или краткий итог). Требование:
использовать связку операторов | и grep для отбора файлов,
использовать rm с ключом(ами), которые показывают удаляемые файлы или спрашивают подтверждение (на выбор),
использовать && и/или || для ветвления на успех/ошибку хотя бы в одном месте.
